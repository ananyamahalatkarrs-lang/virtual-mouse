# AI Virtual Mouse (Gesture Controlled)

Control your computer's mouse cursor, clicks, dragging, scrolling, and window closing in real-time using hand gestures via your webcam.

---

## 🚀 Unique & Core Gestures

| Action | Hand Gesture | Description |
| :--- | :--- | :--- |
| **👋 Close Screen / App** | **Wave 5 Fingers (Bye)** | Open all 5 fingers and wave/hold for ~1.3 seconds. A red progress bar will fill up and automatically close the application! |
| **☝️ Move Cursor** | **Index finger UP** | Smooth, jitter-free cursor tracking with adaptive speed. |
| **🤏 Left Click** | **Thumb + Index quick pinch** | Tap thumb and index finger together to click. Visual green indicator lights up. |
| **🤏 Drag & Drop** | **Thumb + Index hold pinch** | Hold the pinch (> 0.25s) to grab windows, files, or select text; open hand to drop. |
| **🤏🤏 Double Click** | **Thumb + Index double tap** | Double pinch rapidly within 0.35s. |
| **🤟 Right Click** | **3 fingers UP** | Extend Index, Middle, and Ring fingers (or Thumb + Middle pinch). |
| **✌️ Smooth Scroll** | **Peace Sign (Index + Middle)** | Move your hand up or down to scroll web pages and documents smoothly. |
| **✊ Pause / Rest** | **Closed Fist** | Clench into a fist to rest your hand without moving the mouse. |

---

## 💻 How to Run

Double click **`run.bat`** in File Explorer, or open your terminal and run:

```powershell
.\.venv\Scripts\python.exe virtual.py
```

### Keyboard Shortcuts
- Press **`q`** or **`ESC`** in the camera window to quit.
- Press **`r`** to instantly reset the cursor to the center of your screen.
